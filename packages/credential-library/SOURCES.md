# Curated example sources

The following seven unsigned examples are adapted from the FrenchFry Unsigned VC
Library v1 (ZIP version 2, SHA-256
`7b8fc95babb339f029d07fb132e93efd5f67a7296afc0a725ccfb6f6856cd748`).
The corpus was generated by its `scripts/generate.py`; these examples are authored
scenarios, not records of real assessments. Their metadata uses the existing
`source: 'synthetic'`, `signed: false` convention. `validity: 'valid'` describes
structural validity of an unsigned template, not verified issuance or authenticity.

| Fixture                          | Original credential UUID               | Coverage                                                    |
| -------------------------------- | -------------------------------------- | ----------------------------------------------------------- |
| `obv3/food-allergen-practice`    | `7cc497f9-092a-5ea2-8cdb-7a2e60c25e68` | RubricScore with observed practice                          |
| `obv3/food-allergen-facilitator` | `04adda59-747f-5d5b-b287-1a9b1943b2ba` | Teaching scope on the same topic                            |
| `obv3/food-allergen-practice-fr` | `14adf3a3-43d2-5271-90be-9812f906deef` | French text with the same scoring structure and alignment   |
| `obv3/phishing-transfer`         | `670ef7c6-b8de-532c-9667-9817a0c942e8` | Achieved-level-only and raw-score results together          |
| `custom/course-enrollment`       | `6ea43ad2-3fb5-55dd-aee8-6380b7ec0725` | Enrollment without completion or assessed attainment        |
| `custom/exam-accommodation`      | `0e341ee2-6006-51b9-a559-62d7ac21a4e1` | Accommodation without diagnosis or assessed attainment      |
| `clr/mixed-role-portfolio`       | `47213155-4246-5f73-bcf4-54776e488e21` | Three mixed-role children and canonical scalar associations |

Presentation text is shortened and issuer names follow the package's example
conventions. Administrative examples use distinct custom types with inline
JSON-LD mappings. The CLR uses the cached `context.json` URL, following the other
CLR fixtures. Credential UUIDs and reserved example-domain identifiers remain
deterministic; `prepareFixture` makes fresh UUIDs when requested. The CLR's
achievement list mirrors child definitions and does not add awards. No corpus
evaluation labels, other payloads, generator, or shared generation templates are
imported. The French example is a counterpart, not a second independent scoring
case.

Issuer profiles reuse existing fictional examples: Cedar Technical Training
(`clr/training-provider-record`), Tech Academy (`obv3/full-badge`), Community College
XYZ (`clr/multi-achievement`), Metropolis University – Office of the Registrar
(`vc-v2/education-degree`), and State University (`obv3/micro-credential`). The five
issuer groups remain distinct; the CLR and its three children share the Community
College XYZ profile. Administrative contexts define the profile and URL terms
without adding achievement claims. These display profiles do not assert issuer
trust or verification, and the original corpus release is unchanged.
