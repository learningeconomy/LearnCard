# AI Passport

Astro and React frontend for AI Passport.

## Commands

Run these commands from `apps/ai-passport`:

| Command            | Action                                   |
| :----------------- | :--------------------------------------- |
| `bun run dev`      | Start the local app at `localhost:4321`  |
| `bun run build`    | Build the production app                 |
| `bun run preview`  | Preview the production build             |
| `bun run test:e2e` | Run the Playwright end-to-end test suite |
| `bun run astro`    | Run Astro CLI commands                   |

Copy `.env.example` to `.env` when local backend or LearnCard URL overrides are needed.
