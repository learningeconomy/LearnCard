# Getting Help with LearnCard

Pick the door that matches what you need. Each one goes to a place that is actively watched.

## Something is broken, or you have a technical question

**[Open an issue on GitHub](https://github.com/learningeconomy/LearnCard/issues/new/choose).** Bugs and developer questions live next to the code, where they can be linked to fixes. Search existing issues first — someone may have hit the same thing.

Include the package and version (`@learncard/init`, `@learncard/network-plugin`, …), what you expected, what happened, and the smallest snippet that reproduces it.

## You want a feature, or want to see what's coming

**[roadmap.learncard.com](https://roadmap.learncard.com)** — request features, vote on other people's requests, and follow the public roadmap. Release notes are on the [changelog](https://roadmap.learncard.com/changelog).

Please use the roadmap rather than GitHub Issues for feature requests: voting is what lets us see which ideas matter to the most people.

## You're reading the docs and stuck

**[docs.learncard.com](https://docs.learncard.com)** — start with [What Do You Want to Build?](https://docs.learncard.com/start-here/what-do-you-want-to-build) or the [Quickstart](https://docs.learncard.com/start-here/your-first-integration). If a page is wrong or missing, open an issue and tag it `documentation`.

## Private, commercial, or partnership questions

Email **[sdk@learningeconomy.io](mailto:sdk@learningeconomy.io)** or use the [contact form](https://www.learningeconomy.io/contact). For security issues, email **security@learningeconomy.io** rather than opening a public issue.
