# Glossary

| Term                                                                                                                                                                                                       | Definition                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Verifiable Credential (VC)**                                                                                                                                                                             | A digital certificate or badge — like a diploma or skill badge — that is cryptographically signed so anyone can verify it's authentic, and owned by the person who earned it. Based on the [W3C standard](https://www.w3.org/TR/vc-data-model-2.0/). |
| **DID (Decentralized Identifier)**                                                                                                                                                                         | A user-owned identifier (like `did:key:z6Mk...`) that works across systems without a central registry. Every LearnCard user and issuer has one.                                                                                                      |
| **Boost**                                                                                                                                                                                                  | A LearnCard credential template. Define a badge once, then issue copies of it to many recipients — with optional dynamic fields per recipient.                                                                                                       |
| **Universal Inbox**                                                                                                                                                                                        | LearnCard's delivery system for sending credentials to people who don't have an account yet — by email or phone. Recipients get a claim link.                                                                                                        |
| **ConsentFlow**                                                                                                                                                                                            | A contract-based permission system: users explicitly consent to what data an app can read or write, and can withdraw consent at any time.                                                                                                            |
| **GameFlow**                                                                                                                                                                                               | A ConsentFlow variant for games and apps used by minors, with built-in guardian approval.                                                                                                                                                            |
| **Auth Grant / API Token**                                                                                                                                                                                 | A scoped, static credential for server-to-server API calls (e.g. scope `inbox:write` to send credentials). Created once, then used as a Bearer token.                                                                                                |
| **Seed phrase**                                                                                                                                                                                            | The random secret that deterministically generates your keys and DID. Whoever holds the seed controls the identity.                                                                                                                                  |
| **SSS (Shamir Secret Sharing)**                                                                                                                                                                            | A cryptographic technique that splits a private key into pieces (shares) so no single device or server ever holds the whole key. Powers LearnCard's passwordless key management.                                                                     |
| **Signing Authority**                                                                                                                                                                                      | A service that signs credentials on an issuer's behalf — used for claim links and server-side issuance without exposing the issuer's keys.                                                                                                           |
| **Profile**                                                                                                                                                                                                | An issuer's or user's public identity on the LearnCard Network (profile ID, display name, avatar).                                                                                                                                                   |
| **Presentation (VP)**                                                                                                                                                                                      | A signed bundle of one or more credentials that a holder shares with a verifier, proving the credentials belong to them.                                                                                                                             |
| **OBv3 (Open Badges 3.0)**                                                                                                                                                                                 | The 1EdTech standard for achievement badges, built on Verifiable Credentials. LearnCard's default badge format.                                                                                                                                      |
| **CLR (Comprehensive Learner Record)**                                                                                                                                                                     | A 1EdTech standard for bundling many achievements (courses, degrees, skills) into one verifiable record.                                                                                                                                             |
| **xAPI**                                                                                                                                                                                                   | A standard for recording learning activity statements ("Alice completed Lesson 3"). LearnCloud stores xAPI data tied to user DIDs.                                                                                                                   |
| **CHAPI**                                                                                                                                                                                                  | The Credential Handler API — a browser protocol for wallet-to-site credential exchange. LearnCard is CHAPI-compatible.                                                                                                                               |
| **Trust Registry**                                                                                                                                                                                         | A list of recognized issuers used to show whether a credential comes from a known, trusted source.                                                                                                                                                   |
| **Universal Inbox** — how a credential reaches someone who doesn't have a LearnCard account yet. You send to an email or phone number; they get a claim link; the credential is waiting when they sign up. |

**Template (Boost)** — a reusable definition of a credential. Send from a template and LearnCard fills in each recipient's copy and signs it for you. Every `send` creates one; its address looks like `lc:network:…:boost:…`.

**Signing authority** — a signing service that holds a key and signs credentials on your behalf, so a server or the LearnCard Network can issue for you without your seed being present. LearnCard can host one for you in one click.

**Integration** — your project's identity in the Developer Portal. It owns your API tokens, templates, and app listings.
