# Add LearnCard to Your Product

Let users claim, view, or share credentials from inside your product. Start with the lightest option that fits:

| I want to…                                                                   | Start here                                                                                                                                                              | Effort                             |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| Award a badge when something happens and I know the user's email             | [Send & Issue Credentials](../send-credentials.md) — one `send()` call, no user setup                                                                                   | Minutes                            |
| Add a "claim credential" button to a page                                    | [Embed a Claim Button](embed-a-claim-button.md)                                                                                                                         | One script tag                     |
| Let users link their LearnCard once, then issue automatically (site or game) | [Connect Your Website or Game](connect-a-website.md) · [hands-on tutorial](../../tutorials/create-a-connected-website.md)                                               | A day (backend + consent contract) |
| Run my app inside LearnCard's app store                                      | [Publish Your App](../publish-your-app.md) → [Build an Embedded App](connect-an-embedded-app.md)                                                                        | A few days                         |
| Exchange credentials with any standards-compliant wallet                     | [Interoperate with Any Wallet (VC-API)](../interoperate-with-learncard.md)                                                                                              | Varies                             |
| Read a learner's data with their consent (AI tutor, LMS, career tool)        | [Consent & Guardianship](../../tutorials/create-a-consentflow.md) · [Accessing Consented Data](../../core-concepts/consent-and-permissions/accessing-consented-data.md) | A day                              |

Integrating an LMS or an AI tutor? Both are the connected-account pattern plus consent — start with [Connect Your Website or Game](connect-a-website.md), then [Publish Your App](../publish-your-app.md) if you want to live inside LearnCard. Questions about your setup: [open an issue](https://github.com/learningeconomy/LearnCard/issues/new/choose) or email [sdk@learningeconomy.io](mailto:sdk@learningeconomy.io).
