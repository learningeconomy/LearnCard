-   [Build a Plugin](the-simplest-plugin.md) — extend LearnCard with custom functionality
-   [Remote Key Management](managing-seed-phrases.md) — custody patterns for seeds and keys
-   [SSS Key Management Config](sss-key-management-config.md) — self-hosted passwordless key infrastructure
-   [Generate API Tokens](generate-api-tokens.md) — scoped auth grants for server-to-server calls
-   [Deploy Your Own Network](deploy-your-own-network.md) — run an independent LearnCard network
-   [Connect to Independent Network](connect-to-independent-network.md) — point the SDK at your own infrastructure
