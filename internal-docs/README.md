# Internal Docs

Engineering-internal documentation: implementation notes, design docs, and plans that are tied to this codebase but are **not** published to docs.learncard.com. Public documentation lives in `docs/` (GitBook-synced).

| Folder                  | What goes here                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| `implementation-notes/` | Feature/system notes for engineers (AI contracts, data sharing, feature summaries, etc.) |
| `architecture/`         | Internal architecture and design documents                                               |
| `plans/`                | Dated project plans and specs (historical record)                                        |
| `app-flows/`            | App feature flow documentation (AI insights, pathways)                                   |

If a page here becomes partner-facing, move it into `docs/` and add it to `SUMMARY.md`.
