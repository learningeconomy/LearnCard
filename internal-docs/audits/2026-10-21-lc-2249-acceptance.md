# LC-2249 / PR #1720 acceptance audit

Audited 2026-10-21 against the live [LC-2249](https://welibrary.atlassian.net/browse/LC-2249) description and source at `47405e175`, followed by the test-only additions in this PR. No Jira requirements were edited.

## Disposition

The implementation covers import detection, opt-in standard field routing, recipient-specific values, and Paraglide for the new UI copy. **The complete real-export acceptance criterion is still open.** Actual Google Sheets CSV/XLSX exports are now retained as regression fixtures; the Excel probe uses an official template, and Canvas coverage uses an upstream fixture. Neither of the latter establishes acceptance with a freshly exported populated roster.

## Remaining acceptance work and scope notes

1. The workspace/Include presentation and explicit-unit treatment for Hours are intentional adaptations of the ticket wording, reflecting the design and standards decisions already made in this work. They are documented here rather than silently treated as the original presentation.
2. For a Canvas export containing only SIS/Canvas IDs, should the issuer add an email column first? Current scope safely requires emails and does not resolve institutional IDs to delivery addresses. Supporting that lookup would require a separate authenticated integration and identifier-matching rules.
3. Obtain an actual sanitized Canvas export and a populated Excel-saved roster, retain provenance, and run the same mapping/validation cases. Public examples and derivatives must remain labeled as such.
